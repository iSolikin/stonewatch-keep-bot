# Stonewatch Keep Bot

**Автоматизация повседневных действий в Stonewatch Keep.** Браузерное расширение помогает вести игровой цикл по настроенным правилам.

## Возможности

- Собирает доступное производство и награды за квесты.
- Строит и улучшает здания, управляет наймом и размещением армии.
- Показывает расчёты и действия в панели расширения.
- Поддерживает пробный прогон перед включением действий.

**Подписи кошельком и вывод средств остаются за пользователем.** Бот не выполняет эти операции автоматически.
