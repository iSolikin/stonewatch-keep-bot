# Stonewatch Keep Bot

Расширение для повседневных задач в Stonewatch Keep: сбор производства, квесты, строительство и управление армией.

### Возможности

- Собирает доступные ресурсы и награды.
- Развивает постройки и распределяет солдат по выбранной стратегии.
- Показывает план действий в пробном режиме перед запуском.
- Ведёт журнал работы, чтобы было видно, что произошло в игре.

Вход и операции с кошельком остаются под вашим контролем.
